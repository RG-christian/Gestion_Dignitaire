================================================================================
  COMMENT EXÉCUTER LA MIGRATION ?
================================================================================

MÉTHODE SIMPLE (Recommandée) :
------------------------------
1. Assurez-vous que MAMP est démarré (Apache + MySQL actifs)
2. Double-cliquez sur : migrate-and-seed.bat
3. Attendez que ce soit terminé
4. C'est fait !

MÉTHODE MANUELLE :
------------------
1. Ouvrez un terminal
2. cd c:\MAMP\htdocs\Gestion_Dignitaire\gestion-dignitaire-v2\backend
3. php artisan migrate:fresh --seed
4. php artisan config:clear
5. C'est fait !

✅ Commandes Artisan puissantes
✅ Suivi des versions automatique
✅ Facile à déployer en production
